# Stitch v2 — Structural Analysis (design HTML vs current implementation)

Scope: PAGE STRUCTURE ONLY (grids, card anatomy, KPI strips, table rows, spacing, max-widths). Nav bars / sidebars / top menus in the HTML are ignored — app nav is finalized. Colors/fonts/tokens ignored in deltas.

Design-token legend used across all screens (from the HTML Tailwind configs): `gutter`/`stack-md` = 24px, `stack-sm` = 12px, `card-padding` = 32px, `section-gap` = 64px. Surfaces are `glass-panel`/`glass-card` (semi-transparent white + blur-20px + 1px white border) on a `#f8f9ff` canvas with ambient radial-gradient/blur blobs. Two style sources exist: `clinical_precision/DESIGN.md` (enterprise-dense: 24px container padding, 4–8px radii, 8px table cell padding-y, 400px peek drawer, bordered white cards not glass) and `luminous_3d_precise/DESIGN.md` (premium airy: 64px section gaps, 32px card padding, ≥24px radii, pill buttons, glassmorphism). The exported screens predominantly follow luminous_3d_precise spacing with glass surfaces.

## Common patterns (structural rules shared across all 16 screens)

- **Page container**: `max-w-7xl mx-auto` content cap on most pages (exceptions: dashboard bento `max-w-[1400px]`, leads table `max-w-[1600px]`, leads card view + parties list full-width inside the canvas, territories = full-viewport split with no page scroll, settings = floating `max-w-7xl rounded-4xl min-h-85vh` window). Page padding 24–32px (`p-gutter` to `p-card-padding`); current app routes use `space-y-5` (20px) rhythm and mixed max-w (some none, some 6xl/7xl) — normalizing to max-w-7xl is a global ticket.
- **Vertical rhythm**: `space-y/gap` = `section-gap` 64px between major sections, 24px between cards within a section. Current app is uniformly 20px.
- **Page header pattern**: left title block (`headline-xl` 40px title + `body-lg` subtitle, sometimes uppercase eyebrow or breadcrumb row, sometimes inline count pill) + right action cluster of pill buttons (`rounded-full px-6 py-2.5–3`, glass secondary + primary gradient). Headers are `flex justify-between items-end`.
- **KPI strip pattern**: `grid md:grid-cols-3 lg:grid-cols-4 gap-6` of glass cards `rounded-2xl p-8` with decorative blur blob/watermark icon, anatomy = icon chip + uppercase `label-md` label → 32–40px value → delta chip / "N items" line / action link. (Dashboard variant: one panel with divider-separated stats instead of separate cards.)
- **Filter bar pattern**: single glass bar `rounded-2xl p-4` holding segmented lens pills (inset track `rounded-full p-1`, active white/primary pill), filter dropdown pills, and a rounded search input (`pl-10, w-48–64`); alternatively folded into the table card's header row (`p-6 border-b`, title left, search+filters right).
- **Card anatomy**: `rounded-2xl p-8` (or `p-5/6` for dense grids), optional decorative corner blob, optional 4px left accent bar, hover `-translate-y-1`; footers `mt-auto pt-4 border-t` with a big figure + 40px circular arrow CTA.
- **Table card pattern**: glass card `rounded-2xl overflow-hidden`; header bar `px-6 py-4 border-b` (title + filter/search right); header cells `py-4 px-6` uppercase labels; row anatomy = 32–40px initials avatar + two-line text (name semibold + secondary subline); status = dot-pill `px-3 py-1 rounded-full text-xs`; actions = single chevron or pill button.
- **Pagination footer**: `px-6 py-4 border-t flex justify-between` — "Showing X to Y of Z" left, prev/next (+numbered pages) right; long grids use a centered "Load More" button instead.
- **Selection model** (tables): always-on checkbox column + floating bottom-center glass pill action bar (`rounded-full px-6 py-3`) vs the app's explicit select-mode toggle.
- **Side panels**: sticky right detail column `w-72/80/96`, `sticky top-6`, with 2-col quick-stats grid, icon-circle contact rows, tag chips, bottom-pinned action button (transporters, territories, settings log, lead detail right column).
- **Empty states**: centered icon (64px) + headline + body copy + outlined pill CTA, `min-h-[300px]` card — replaces plain muted text.
- **Segmented lens controls**: inset-track pill groups (All/Active/Pending, Directory/Accounts, lens tabs) in header or filter bar — the app currently expresses these as separate routes or Select dropdowns.
- **Badges/pills**: status always `rounded-full px-3 py-1 text-xs` (optionally with `w-1.5` dot); metadata chips `px-2 py-0.5/1 rounded-md text-[10–12px]`; counts as inline title pills.
